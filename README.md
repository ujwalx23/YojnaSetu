# Scheme Suggestor

A web application designed to help users discover and find relevant government schemes and benefits tailored to their eligibility criteria.

## Getting Started

This repository is connected to [https://github.com/ujwalx23/Scheme-Suggestor](https://github.com/ujwalx23/Scheme-Suggestor).

### Setup & Installation

```bash
# Clone the repository
git clone https://github.com/ujwalx23/Scheme-Suggestor.git

# Navigate into project folder
cd Scheme-Suggestor
```
